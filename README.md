# 家庭支出账本

记录2026年9月、10月家庭固定支出与1号、2号非固定支出，提供月份切换、分类汇总、个人总结和明细类别筛选。

## 查看账本

下载仓库后，使用浏览器打开 `index.html`，无需构建或启动服务器。页面的字体和图标使用在线资源；金额、明细和筛选由本地文件提供。

- `家庭支出整理.md`：账本说明、月度汇总及流水核对。
- `app.js`、`styles.css`：页面展示与交互。
- `october-*.js`、`september-one-alipay-data.js`：流水数据、去重规则和金额计算。
- `outputs/`：历史Excel导出，未同步本次网页的全部后续调整；最新统计以网页和MD文档为准。
- `build_family_expenses.mjs`：历史Excel编辑脚本，需要原运行环境中的依赖。
- `.preview/verify-october.mjs`：数据金额、退款去重、月份切换、类别筛选及手机布局的检查脚本，需要Playwright和Microsoft Edge。
